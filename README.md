### A Linux Discord Client

Recar is a Discord client for Linux with client mods and extra functionality.  
https://recar.loxodrome.app/

<img width=640 src="repository/recarshowcase.png">

</div>

> [!WARNING]
> Recar is still in alpha! Things may be broken, missing, or change unexpectedly.

## Features

- RPC server built in (for Rich Presence)
- Custom call popup when ringing
- Switch between Vencord & Equicord
- Wayland Streaming
- Streaming from OBS Studio (no audio at the moment)
- Superior Desktop Notifications
- Recar exclusive plugins ("CatboxUpload" and "ControllerSupport(Experimental)" for now)
